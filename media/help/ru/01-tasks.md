# Задачи и приоритеты

Задача — заголовок markdown, текст которого начинается с ключевого слова.
Больше ничто её не отмечает: файл остаётся файлом markdown, и читатель, у
которого расширение не установлено, видит заголовок со словом перед ним.

```markdown
## TODO [#A] Продлить сертификат TLS
SCHEDULED: <2026-09-09 Ср>
```

## Ключевые слова

| Слово       | Что означает                                         |
| ----------- | ---------------------------------------------------- |
| `TODO`      | открыта, и агенда показывает её, пока она не закрыта |
| `DONE`      | закрыта как выполненная                              |
| `CANCELLED` | закрыта как снятая, и считается отдельно от `DONE`   |

Три команды ставят их на заголовок, в котором стоит курсор:

- `markdown-org.setTodo` — **Set TODO**
- `markdown-org.setDone` — **Set DONE**; у повторяющейся задачи закрывает не
  задачу, а очередной повтор, см. раздел о повторах
- `markdown-org.setCancelled` — **Set CANCELLED**

Повторный запуск той же команды на заголовке, который уже несёт это слово,
снимает его, поэтому пары команд хватает, чтобы заводить заголовок в агенду и
убирать из неё.

## Приоритеты

Приоритет — метка сразу после ключевого слова: `[#A]`, `[#B]`, `[#C]` либо
число от `[#0]` до `[#64]`. Буквы и числа упорядочиваются вместе — `A` это `0`,
`B` это `1`, `C` это `2`, — поэтому файл может пользоваться тем из двух, что
читается лучше.

- `markdown-org.togglePriority` — **Toggle Priority** перебирает A, B, C и
  «без приоритета»; это самый быстрый способ поднять одну задачу над другой.
- `markdown-org.setPriority` — **Set Priority** спрашивает значение и принимает
  число наравне с буквой.

Агенда красит задачу по приоритету и сортирует по нему внутри дня.

## Перенос заголовка из файла

Две команды переносят заголовок целиком, со всем, что под ним, в другой файл:

- `markdown-org.moveToArchive` — **Move to Archive** дописывает его в
  `<файл>.archive.md` рядом с исходным. Закрытые задачи, которые файлу больше
  не нужны, остаются читаемыми и не утяжеляют его.
- `markdown-org.promoteToMaintain` — **Promote to Maintain** переносит его в
  файл, названный настройкой `markdown-org.maintainFilePath`. Задача, ставшая
  постоянной обязанностью, живёт там, а не в заметках того дня, когда она
  появилась.

## Метки по файлам

Метка — это отбор по именам файлов, а не пометка внутри файла. Их объявляет
`markdown-org.fileTags`, и каждый каталог заметок может объявить свои.
`ALL` подходит ко всему, `WORK` — к файлам, в пути которых есть `work`, а
`!work` — к тем, у которых его нет.

- `markdown-org.cycleTag` — **Cycle Tag Filter** перебирает метки в агенде.
- `markdown-org.showTagDictionary` — **Show File Tags** показывает, какие метки
  есть и какие файлы они охватывают.
- `markdown-org.currentTag` хранит действующую метку; у каждой рабочей области
  своя.
