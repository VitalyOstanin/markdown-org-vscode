# Значок git в агенде

Заметки, которые ведутся в git, читаются больше чем на одной машине, и их
состояние уместно рядом с задачами, а не в другом окне. Значок справа в шапке
агенды считает файлы, стоящие за текущим видом, по состояниям:

| Знак | Что считает                                                                                                    |
| ---- | -------------------------------------------------------------------------------------------------------------- |
| `!`  | неразрешённые конфликты                                                                                        |
| `●`  | незакоммиченные изменения                                                                                      |
| `↑`  | файлы, затронутые коммитами, которых нет на сервере                                                            |
| `?`  | файлы, состояние которых прочитать не удалось: вне git либо в репозитории, который VS Code открывать отказался |

Развёрнутый значок называет эти файлы, группирует их по тем же состояниям и
перечисляет коммиты, которые уйдут при push. Каждый знак по наведению говорит
свою часть, а не выдаёт все четыре разом.

## Четыре действия

Все четыре работают над файлами текущего вида, а не над всем, что лежит в
репозитории:

| Действие            | Что делает                                                                           |
| ------------------- | ------------------------------------------------------------------------------------ |
| **Commit**          | коммитит эти файлы, не трогая посторонние правки в том же репозитории                |
| **Commit and sync** | два действия подряд — заметка, написанная здесь и прочитанная на телефоне            |
| **Push**            | отправляет ветку                                                                     |
| **Sync**            | fetch, перемотка ветки, которая только отстала, и push той, которая только опередила |

Ветка, которая разошлась, остаётся ровно как есть и называется: слияние — это
решение, принимаемое в Source Control, а не панелью. Коммит, отменённый
пользователем или отвергнутый git, останавливает круг до синхронизации.

Git коммитит весь индекс, поэтому о репозитории, где что-то добавлено в индекс
со стороны, спрашивают до коммита. Неразрешённое слияние убирает действие
коммита, пока оно не улажено в Source Control.

Запросы, отказы и подтверждения этих действий говорят на языке, выбранном
настройкой `markdown-org.uiLanguage`, как и остальная панель.
