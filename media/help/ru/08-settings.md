# Все настройки одним списком

Настройки живут под `markdown-org` в обычных настройках VS Code, а разделы выше
говорят, где каждая из них важна. Эта страница — сам список: что настройка
задаёт и что в ней, пока её не трогали.

## Файлы, которые читает агенда

| Настройка                       | По умолчанию             | Что задаёт                                                                                                |
| ------------------------------- | ------------------------ | --------------------------------------------------------------------------------------------------------- |
| `markdown-org.workspaceDirs`    | пусто                    | каталоги, которые обходятся и показываются одной агендой, каждый со своим цветом                          |
| `markdown-org.workspaceDir`     | пусто                    | единственный каталог; читается, когда список выше пуст, а пустое значение означает корень рабочей области |
| `markdown-org.maintainFilePath` | пусто                    | файл, в который **Promote to Maintain** переносит заголовок; пустое значение выключает команду            |
| `markdown-org.extractorPath`    | пусто                    | ваша сборка ядра; пустое значение означает двоичный файл внутри расширения                                |
| `markdown-org.fileTags`         | `ALL`, `WORK`, `PRIVATE` | метки по именам файлов, объединяемые с теми, что объявляет каждый каталог заметок                         |
| `markdown-org.currentTag`       | `ALL`                    | действующая метка; у каждой рабочей области своя                                                          |

## Даты и язык

| Настройка                     | По умолчанию | Что задаёт                                                     |
| ----------------------------- | ------------ | -------------------------------------------------------------- |
| `markdown-org.dateLocale`     | `en-US`      | как форматируются даты, которые показывает агенда              |
| `markdown-org.weekdayLocale`  | `ru`         | язык дня недели, записываемого в метку времени: `Пн` или `Mon` |
| `markdown-org.uiLanguage`     | `auto`       | язык панели и сообщений действий, запущенных из неё            |
| `markdown-org.firstDayOfWeek` | `monday`     | день, с которого начинаются неделя и календарь месяца          |

## Как выглядит агенда

| Настройка                        | По умолчанию | Что задаёт                                                            |
| -------------------------------- | ------------ | --------------------------------------------------------------------- |
| `markdown-org.agendaGrouping`    | `sections`   | делится ли день на разделы с заголовками или отдаётся одними строками |
| `markdown-org.agendaHeaderMode`  | `auto`       | полная шапка или сжатая                                               |
| `markdown-org.agendaFontFamily`  | пусто        | пропорциональный набор шрифтов панели                                 |
| `markdown-org.highlightInEditor` | `true`       | красятся ли конструкции org в редакторе markdown                      |

## Учёт времени

| Настройка                        | По умолчанию | Что задаёт                                                                            |
| -------------------------------- | ------------ | ------------------------------------------------------------------------------------- |
| `markdown-org.clockRoundMinutes` | `0`          | до скольких минут округляется записываемая отметка `CLOCK`; `0` пишет минуту как есть |

## Google Calendar

| Настройка                                    | По умолчанию   | Что задаёт                                                                |
| -------------------------------------------- | -------------- | ------------------------------------------------------------------------- |
| `markdown-org.gcalSync.authProvider`         | `auto`         | откуда берётся токен доступа                                              |
| `markdown-org.gcalSync.clientId`             | пусто          | идентификатор клиента OAuth Desktop, когда токен берётся у своего клиента |
| `markdown-org.gcalSync.goaAccount`           | пусто          | учётная запись GNOME Online Accounts, у которой берётся токен             |
| `markdown-org.gcalSync.calendarName`         | `markdown-org` | имя, под которым календарь находится или создаётся                        |
| `markdown-org.gcalSync.calendarId`           | пусто          | закреплённый календарь; он важнее имени                                   |
| `markdown-org.gcalSync.syncOnSave`           | `false`        | запускает ли сохранение файла синхронизацию                               |
| `markdown-org.gcalSync.syncOnSaveDebounceMs` | `5000`         | сколько этот запуск ждёт остановки набора                                 |
| `markdown-org.gcalSync.concurrencyPolicy`    | `queue`        | что делает синхронизация, запрошенная во время идущей                     |
| `markdown-org.gcalSync.onDone`               | `delete`       | что происходит с событием задачи, ставшей `DONE`                          |
| `markdown-org.gcalSync.defaultEventMinutes`  | `60`           | сколько длится событие, когда конец не назван                             |
