## Состав

Месячный вид агенды — календарная сетка со следующими возможностями.

### Функциональность

1. **Календарная сетка 7 колонок** — месяц с подписями дней недели; число строк
   (4/5/6) добирается до полной недели ведущими и хвостовыми ячейками соседних
   месяцев
2. **Кликабельные дни** — каждая ячейка это `<button>`; клик открывает day view
   этого дня, подсказка та же, что у заголовка дня в недельном виде
3. **Индикация загрузки дня** — чип-счётчик в правом нижнем углу ячейки с числом
   задач; чип краснеет, если среди них есть просроченные. Число задач в подсказке
   расшифровано словами
4. **Выходные дни** — суббота и воскресенье с лёгкой подложкой
5. **Праздничные дни** — подложка с красным оттенком
6. **Текущий день** — акцентное кольцо (внутренний `outline`, чтобы размер ячейки
   не менялся) и выделенный номер дня
7. **Навигация по месяцам** — группа Prev / Today / Next в липкой верхней панели,
   общая для всех видов агенды; первый день недели задаётся настройкой
   `markdown-org.firstDayOfWeek`

### Визуальные индикаторы

Цвета не захардкожены: все значения приходят из токенов темы VS Code
(`var(--vscode-*)`), а оттенки собираются `color-mix()` от них — поэтому светлая,
тёмная и высококонтрастная темы поддерживаются автоматически. Инвариант закреплён
unit-тестом (`src/test/unit/agendaStyles.test.ts`).

| №   | Элемент              | Оформление                                                                 |
| --- | -------------------- | -------------------------------------------------------------------------- |
| 1   | Обычный день         | прозрачный фон, рамка `--vscode-panel-border`, скругление `--radius-md`    |
| 2   | Выходной день        | подложка: `--vscode-foreground` 5% над фоном редактора                     |
| 3   | Праздничный день     | подложка: `--vscode-charts-red` 12% над фоном редактора                    |
| 4   | День с задачами      | чип-счётчик (`--vscode-badge-*`), номер дня обычным цветом текста и жирным |
| 5   | День с просрочкой    | тот же чип на акцентном красном (`--accent-red`)                           |
| 6   | Текущий день         | кольцо `--vscode-focusBorder` и номер дня цветом активной ссылки           |
| 7   | Дни соседних месяцев | та же ячейка с `opacity: 0.35`                                             |

### Праздничные дни

Источник данных -- `markdown-org-extract --holidays <YEAR>`. Команда
возвращает JSON-массив дат (YYYY-MM-DD), который webview ищет линейно
через `isHoliday(date)`:

```js
function isHoliday(date) {
    return holidays.includes(date);
}
```

Список не хардкодится в расширении -- актуальные даты задаются в
извлекалке (см. `markdown-org-extract`). Если извлекалка не отдала праздники,
календарь рендерится без них, а причина пишется в канал вывода «Markdown Org».

### Технические детали

1. **Файлы**:
    - `src/webview/agendaClient.ts` — код, выполняющийся в самой странице
      (`renderMonthCalendar`, `calendarCellOpenTag`, `isHoliday`, `navigateToDay`)
    - `src/views/agendaPanel.ts` — хост-сторона: панель, сообщения, оболочка HTML
    - `src/utils/agendaMonthCells.ts` — `buildMonthDayIndex(days)`: сводка
      «дата → { total, overdue }», покрытая unit-тестами
    - `src/views/agendaStyles.ts` — таблица стилей календаря
2. **Источник праздников**: хост вызывает `markdown-org-extract --holidays <year>`,
   разбирает JSON и передаёт массив в webview сообщением (см. `holidays` в
   `agendaPanel.ts`)
3. **Обработка кликов**: при клике на день отправляется сообщение с флагом
   `switchToDay: true`
4. **Переключение вида**: панель переиспользуется, режим и якорная дата
   записываются в историю переходов (Back / Forward)

## Использование

1. Откройте Agenda Month: `Ctrl+K Ctrl+K Ctrl+M` либо `Ctrl+Shift+P` → «Markdown Org: Show Agenda (Month)»
2. Кликните на любой день, чтобы открыть его в режиме дня
3. Переходите между месяцами кнопками Prev / Today / Next в верхней панели;
   `Alt+Shift+-` и `Alt+Shift+=` возвращают по истории просмотренных видов

## Тестирование

```bash
npm test                                     # unit, включая buildMonthDayIndex и инварианты стилей
node ./scripts/run-integration-tests.js      # интеграционные (на Linux раннер сам поднимает xvfb)
```

Ручная проверка: открыть месячный вид на месяце с задачами и убедиться, что чипы
показывают число задач, красный чип стоит на днях с просрочкой, а клик по ячейке
открывает день.
